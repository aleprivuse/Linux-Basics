# Installing Commands

## Important things to remember

Here is the most important thing to learn, if you want to install or remove a file you need to always put `sudo` before anything else because without it the Linux server is going to say access denied, so remember to always put `sudo`.

`apt` stands for = Advanced Package Tool (a package is a software)

## Commands

1. `sudo apt update` = it's going to refresh the list of the most recent software
2. `sudo apt upgrade` = it's going to update all the software
3. `sudo apt install "the name of the package/software"` = it's going to install a software
4. `sudo apt remove "the name of the package/software"` = it's going to remove it
5. `sudo apt search "the name of the package/software"` = it's going to search it
6. `apt list --installed` = it's going to give you a list of all the installed software
